总结雷达原理课程的所有公式。


# 公式总结


|          名称           |                                                                                                              公式                                                                                                              |
| :-------------------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|        雷达基本方程         |                                                     $$R_{\mathrm{max}}=\sqrt[4]{ \frac{P_{\mathrm{t}}G_{\mathrm{t}}A_{\mathrm{r}}\sigma}{(4\pi)^{2}S_{\mathrm{min}}} }$$                                                     |
|       若收发共用天线，则       |                                                          $$R_{\mathrm{max}}= \sqrt[4]{ \frac{P_{\mathrm{t}}G^{2}\lambda^{2}\sigma}{(4\pi)^{3}S_{\mathrm{min}}} }$$                                                           |
|     识别系数（最小输出信噪比）     |                                                                                      $$M=\left( \frac{S}{N} \right)_{\mathrm{o\ min}}$$                                                                                      |
|        最小可检测信号        |                                                                                 $$S_{\mathrm{i\ min}}=kT_{0}B_{\mathrm{n}}F_{\mathrm{n}}M$$                                                                                  |
|        玻尔兹曼常数         |                                                                                            $$k=1.38\times 10^{-23}\ \text{J/K}$$                                                                                             |
|     用识别系数表示的雷达方程      |                                 $$R_{\mathrm{max}}= \sqrt[4]{ \frac{P_{\mathrm{t}}G_{\mathrm{t}}^{2}\lambda^{2}\sigma}{(4\pi)^{3}kT_{0}B_{\mathrm{n}}F_{\mathrm{n}}ML} }$$（$L$ 为损失系数，$L>1$）                                  |
|          瑞利区          |                                                                                    $$2\pi r\ll\lambda$$此时 $\sigma_{球}\propto\lambda^{-4}$                                                                                    |
|          振荡区          |                                                                                                      $$2\pi r=\lambda$$                                                                                                      |
|          光学区          |                                                                                                     $$2\pi r\gg\lambda$$                                                                                                     |
|        积累改善因子         |                                     单个脉冲观测时所需信噪比与积累 $n$ 个脉冲后，每个脉冲所需信噪比的比值$$I_{\mathrm{i}}(n)=\frac{\left( \frac{S}{N} \right)_{1}}{\left( \frac{S}{N} \right)_{n}}=nE_{\mathrm{i}}(n)$$                                      |
|       积累后的雷达方程        |                                  $$R_{\mathrm{max}}= \sqrt[4]{ \frac{P_{\mathrm{t}}G_{\mathrm{t}}^{2}\lambda^{2}\sigma}{(4\pi)^{3}kT_{0}B_{\mathrm{n}}F\left( \frac{S}{N} \right)_{n}L} }$$                                  |
|         脉冲积累数         |                                                       1. 速度慢时：$$n=f_{\mathrm{r}}T_{\mathrm{M}}$$<br>2. 速度快时：$$n=\frac{\theta_{0.5}}{\varOmega_{\beta}}f_{\mathrm{r}}$$                                                       |
|        雷达直视距离         |                              $$d_{0}\approx \sqrt{ 2a_{\mathrm{e}} }\left( \sqrt{ h_{1} }+\sqrt{ h_{2} } \right)$$其中 $\sqrt{ 2a_{\mathrm{e}} }=4.12$，$h_{1}$ 与 $h_{2}$ 的单位为米，算出的 $d_{0}$ 单位为千米                               |
|   发射机输出平均功率和峰值功率的关系   |               $$\overline{P}=\hat{P} \frac{\tau}{T_{\mathrm{r}}}=\hat{P}\tau F_{\mathrm{r}}$$其中 $F_{\mathrm{r}}=\frac{1}{T_{\mathrm{r}}}$ 为脉冲重复频率，$\frac{\tau}{T_{\mathrm{r}}}=\tau F_{\mathrm{r}}=D$ 称为雷达工作比                |
|         噪声系数          |                                        $$F=\frac{\frac{S_{\mathrm{i}}}{N_{\mathrm{i}}}}{\frac{S_{\mathrm{o}}}{N_{\mathrm{o}}}}=\frac{N_{\mathrm{o}}}{N_{\mathrm{i}}G_{\mathrm{a}}}$$                                         |
|         距离分辨率         |                                                                $$\Delta r_{\mathrm{c}}=\frac{c}{2}\tau$$或$$\Delta r_{\mathrm{c}}=\frac{c}{2B}$$其中 $B$ 为信号有效带宽                                                                |
|     脉冲法测距最大不模糊距离      |                                                                                        $$R_{\mathrm{max}}=\frac{cT_{\mathrm{r}}}{2}$$                                                                                        |
|    二重复频率法回波时延的间接计算    | $$t_{\mathrm{R}}=\frac{t_{1}f_{\mathrm{r}1}-t_{2}f_{\mathrm{r}2}}{f_{\mathrm{r 1}}-f_{\mathrm{r 2}}}$$若上式求得的结果为负，则代入$$t_{\mathrm{R}}=\frac{t_{1}f_{\mathrm{r}1}-t_{2}f_{\mathrm{r}2}+1}{f_{\mathrm{r 1}}-f_{\mathrm{r 2}}}$$ |
| 二重复频率法解模糊的最大不模糊测距的距离  |                                                                       $$R_{\mathrm{max}}=\frac{cT_{\mathrm{r1}}N}{2}=\frac{cT_{\mathrm{r2}}(N+a)}{2}$$                                                                       |
|      “舍脉冲”法的目标距离      |                                                                             $$R=\frac{c}{2}(NT_{\mathrm{r}}+t_{\mathrm{R}}')$$其中 $N$ 为回波跨越的重复周期数                                                                             |
| 采用“舍脉冲”法测距时最大不模糊测距距离为 |                                                                                       $$R_{\mathrm{max}}=\frac{cMT_{\mathrm{r}}}{2}$$                                                                                        |
|      数字脉冲测距目标距离       |                                                                                                     $$R=\frac{cn}{2f}$$                                                                                                      |
|   连续三角波调制的目标距离    |                                                                               $$R=\frac{c}{8f_{\mathrm{A}}} \frac{\Delta F'}{f_{\mathrm{m}}}$$                                                                               |
|       相位法无模糊测距        |                                                                                                $$R=\frac{c\varphi}{2\omega}$$                                                                                                |
|      相位法无模糊测距范围       |                                                                                          $$R_{\mathrm{max}}=\frac{c2\pi}{2\omega}$$                                                                                          |
|    相位法测距解模糊方法     |                                                                                             $$R=\frac{\varPhi c}{4\pi\Delta f}$$                                                                                             |
|      相位法解模糊测距的范围      |                                                                                           $$R_{\mathrm{max}}=\frac{c}{2\Delta f}$$                                                                                           |
|         相位法测角         |                                                                                         $$\varphi=\frac{2\pi}{\lambda}d\sin\theta$$                                                                                          |
|        相位法测角误差        |                                                                            $$\mathrm{d}\theta=\frac{\lambda}{2\pi d\cos\theta}\mathrm{d}\varphi$$                                                                            |
|      相位法无模糊测角范围       |                                                                                     $$\theta_{\mathrm{max}}=\arcsin \frac{\lambda}{d}$$                                                                                      |
|         多普勒频率         |                                                                                   $$f_{\mathrm{d}}=\frac{2v}{\lambda}\cos\theta$$（靠近雷达为正）                                                                                    |
|        出现盲速的条件        |                                                                                              $$f_{\mathrm{d}}=nf_{\mathrm{r}}$$                                                                                              |
|         第一盲速          |                                                                                    $$v_{\mathrm{r0}}=\frac{1}{2}\lambda f_{\mathrm{r}}$$                                                                                     |
|         各盲速的值         |                                                                                     $$v_{\mathrm{r}}=\frac{n}{2}\lambda f_{\mathrm{r}}$$                                                                                     |
|    最大无模糊距离和第一盲速的关系    |                                                                                   $$R_{0\mathrm{max}}v_{\mathrm{r0}}=\frac{\lambda c}{4}$$                                                                                   |
|      产生频闪的条件      |                                                                                     $$v_{\mathrm{r}}>\frac{1}{2}\lambda f_{\mathrm{r}}$$                                                                                     |
|         杂波衰减          |                                                                      输入杂波功率与对消处理后输出信号中同一杂波的剩余功率的比值$$\mathrm{CA}=\frac{C_{\mathrm{i}}}{C_{\mathrm{o}}}$$                                                                      |
|          对消比          |                                                       同一杂波对消后的电压和对消的电压之比$$\mathrm{CR}=\sqrt{ \frac{C_{\mathrm{o}}}{C_{\mathrm{i}}} }=\frac{1}{\sqrt{ \mathrm{CA} }}$$                                                        |
|         改善因子          |               动目标显示系统输出的信号杂波功率比和输入的信号杂波功率比的比值$$I=\frac{\frac{S_{\mathrm{o}}}{C_{\mathrm{o}}}}{\frac{S_{\mathrm{i}}}{C_{\mathrm{i}}}}=G\cdot(\mathrm{CA})=\frac{N_{\mathrm{o}}}{N_{\mathrm{i}}}(\mathrm{CA})$$                |
|        杂波中可见度         |                                                     在给定的检测概率和虚警概率下，雷达输出端信杂比等于可见度系数 $V_{0}$ 时，雷达输入端的功率杂信比$$\mathrm{SCV}(\mathrm{dB})=I(\mathrm{dB})-V_{0}(\mathrm{dB})$$                                                      |
|         斜距分辨率         |                                                                                                     $$\frac{\tau}{2}c$$                                                                                                      |
|         方位分辨率         |                                                                        $$\delta_{\mathrm{a}}=R_{\mathrm{c}}\theta=\frac{R_{\mathrm{c}}k\lambda}{D}$$                                                                         |
|     SAR 地面距离向分辨率      |                                                                               $$\rho_{\mathrm{r}}=\frac{c\tau_{\mathrm{p}}}{2\sin\vartheta}$$                                                                                |
|  脉冲压缩下的 SAR 地面距离向分辨率  |                                                                                 $$\rho_{\mathrm{r}}=\frac{c}{2B_{\mathrm{r}}\sin\vartheta}$$                                                                                 |
|       合成孔径的总长度        |                                                                           $$L_{\mathrm{s}}=\theta R_{\mathrm{c}}=\frac{\lambda}{D}R_{\mathrm{c}}$$                                                                           |
|      合成孔径天线的波束宽度      |                                                                                   $$\theta_{\mathrm{s}}=\frac{\lambda}{2L_{\mathrm{s}}}$$                                                                                    |
|      合成孔径下的方位分辨率      |                                                                             $$\rho_{\mathrm{a}}=R_{\mathrm{c}}\theta_{\mathrm{s}}=\frac{D}{2}$$                                                                              |
|    ISAR 成像纵向距离分辨率     |                                                                                 $$\delta_{\mathrm{r}}=\frac{1}{2}c\Delta \tau=\frac{c}{2B}$$                                                                                 |
|    ISAR 成像横向距离分辨率     |                                                                                    $$\delta_{\mathrm{ra}}=\frac{\lambda}{2\Delta\theta}$$                                                                                    |
