# 字体来源与网页分片

思源宋体源文件为 `SourceHanSerifCN-VF.otf.woff2`，版权归 Adobe 所有，采用 SIL Open Font License 1.1，保留名称为 Source。网页分片的内部字体名称为 Yummy Web Serif VF，原字体的版权、作者、版本与授权记录继续保存在分片中。

LXGW Bright Code GB 的源文件为 `LXGWBrightCodeGB-Regular.ttf`，版权记录包含 LXGW、Klee Project Authors 与 GitHub, Inc.，采用 SIL Open Font License 1.1。其原有 Monaspace 系列保留名称声明继续保存在分片中；网页分片沿用 LXGW Bright Code GB 名称。

网页分片仅调整字符集合与思源字体的内部名称，保留对应字符的轮廓、字宽、适用布局特性及思源可变字重。所有原字体字符均由网页分片覆盖，完整源字体继续保留。

- [思源宋体项目](https://github.com/adobe-fonts/source-han-serif)
- [LXGW Bright Code 项目](https://github.com/lxgw/LxgwBright-Code)
- [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/)
- [网页字体与保留名称说明](https://openfontlicense.org/webfonts-and-reserved-font-names/)

Ubuntu Mono 沿用现有 WOFF2 与 TTF 文件，按 [Ubuntu Font Licence 1.0](https://canonical.com/legal/font-licence) 使用。
