# 视觉与体验持续复核

本次目标：以 Awwwards、Webby Awards、FWA 获奖作品的完成度为参照，持续检查排版、留白、视觉层级、色彩、动效、微交互、响应式与原创性。尚未完成全部维度的终审。

## 设计方向与约束

网站面向阅读工程、物理和开发笔记的人，首页负责帮助读者找到最近发布的内容，文章页负责支持持续阅读、检索与定位。

视觉方向为技术札记。日期、标题、分类与摘要承担不同信息层级；标题驱动的几何纹理作为待完善的识别元素，动效围绕导航、搜索、目录和复制反馈展开。

沿用既有主题色、思源正文与标题字体，以及 Ubuntu Mono / LXGW Bright Code GB 代码字体。个人站强调色为 #f7793c，横幅沿用 #f69128 与 #ff6651，正文为 #24292f，辅助文字为 #6b7280，页面底色为 #ffffff；深色沿用现有令牌。

```text
站点名称                         搜索 / 导航
主题横幅与站点信息
最近发布 / 全部文章               有内容时显示项目
日期
文章标题与分类
摘要
后续文章 / 分页
```

用户已确认保留原来按标题生成的 GeoPattern 配色与纹理显示方式。持续优化以现有主题的视觉风格为约束。

## 首轮验证记录

- 首页改为栏目标题 → 日期 → 文章标题与分类 → 摘要的顺序，标题使用正文前景色，保留主题色分类徽标。
- 有项目时保留双栏，无项目时首页与关于页使用居中的单栏；窄屏项目排列在文章列表之后。
- 修改后 18 组页面截图未见横向溢出或脚本错误；完整浏览器回归覆盖搜索、分类、六级目录、面板、复制、数学公式、图表和 320–768px 布局。
- 规范检查与前端构建通过，本地 UI 构建资源检查通过（1530 项引用）；本地构建沿用临时配置跳过 GitHub metadata，仓库配置未改。
- 以上证明本轮改动可用；八维全站终审仍未完成。横幅色彩、长文排版、性能及更宽的屏幕矩阵继续复核。

## 第二轮调整与用户确认

- 用户反馈统一深色纹理后，恢复原来由标题生成的 GeoPattern 配色和纹理缩放，移除深色底色令牌与横幅装饰线。
- 文章标题独立于日期、分类和副标题；没有元信息时不输出空行。日期使用 `time`，分类兼容文章的 `categories`。
- 缩短内页题头的纵向留白，正文使用适合持续阅读的行距，无目录文章限制行长。
- 首页侧栏和项目页共用项目卡片，显示完整说明，隐藏缺失的统计信息，保持数字 0 正常显示。
- 项目页添加空状态；关闭项目侧栏时隐藏占位。卡片悬停和焦点使用位移与阴影反馈，目录悬停保持字重稳定。
- 当前构建完成 135 组页面检查，覆盖 320、390、768、1024、1440、1920px 的浅深色页面，以及横屏、低可视高度和 200% 缩放等效布局；未见横向溢出、题头信息重叠、描述截断或脚本错误。
- 完整浏览器回归通过，覆盖搜索、六级标题目录、动画面板、焦点、玻璃效果、分类反馈、代码对齐、数学公式、图表与复制。
- 规范检查、前端构建、严格 Jekyll 构建与本地资源引用检查通过。资源检查为 1530 项；本地 UI 构建使用临时配置跳过 GitHub metadata，仓库配置未改。
- 以上是本轮改动的验证记录；全站八维终审仍包含加载性能与真机体验检查。

## 第三轮加载检查

- 对现有代码字体进行格式压缩，不改变字体方案、主题配色或几何纹理。
- LXGW Bright Code GB 从 14,211,668 字节降至 6,190,104 字节；Ubuntu Mono 从 205,748 字节降至 82,416 字节。TTF 原文件保留。
- 核对全部字符映射、字形顺序、轮廓、水平与垂直度量、命名和授权记录、布局表及 hinting 指令；压缩前后一致。
- Chrome 实际字体检查确认英文、中文以及粗斜体仍使用指定组合。1440、320、390、768px 下代码与行号保持对齐；桌面及手机代码区域截图无像素变化。
- 在 390×844px、缓存关闭、下载 1,000,000 字节/秒、延迟 120ms 的本地模拟条件下，示例文章字体请求总量从 24,928,564 降至 16,783,668 字节，全部字体就绪时间从约 27.71 秒缩短至 19.66 秒。
- 以上是本地模拟测量，不能代替真实访问者数据。本轮基线测得约 0.126 的累计布局偏移，主要来自客户端公式渲染；后续修复记录见下文。完整思源字体的冷加载仍需优化，八维终审尚未完成。

## 项目卡片与首页分类反馈修复

- 保留原来的标题纹理颜色，移除卡片悬停的主题色描边与下划线，改用中性描边、白色下划线和纹理内的白色键盘焦点环。位移及阴影反馈继续保留。
- 首页分类标签与标题首行居中对齐，多行标题在右侧自然换行；未填写分类时隐藏空标签，长分类允许换行。
- 检查 320、390、768、1024、1440、1920px 的浅深色首页，共 12 组布局。标签与标题首行行框的最大中心偏差低于 0.01px，文字区域的最大中心偏差低于 0.90px。
- 每组检查三种原始 GeoPattern 纹理的悬停与键盘反馈，纹理图像保持原样；补充长中文标题和无空格英文标识符，未见横向溢出。
- 实际截图复核确认标题与标签对齐，绿色纹理上的悬停反馈不再使用主题色。规范检查、严格 Jekyll 构建、资源引用检查及完整浏览器回归通过。
- 本轮反馈问题已修复；加载稳定性的后续检查见下文。

## 数学公式预渲染复核

- 在 Markdown 转换后、布局合成前使用同版本 KaTeX 预渲染公式，保留 MathML 与原始 LaTeX；关闭 JavaScript 时仍可阅读，启用后支持复制。
- 构建与浏览器共用四种公式标记的识别，跳过代码、脚本、表单、模板、SVG 和原生 MathML。已预渲染文章不再下载公式渲染模块。
- 搜索和 RSS 使用原始正文，避免重复呈现或收录数学标记。搜索索引的字段与内容核对通过；仅两篇文章的行内 `align` 环境改为 `aligned`，表达式保持原样。
- 全部 19 篇文章覆盖 320、390、768、1024、1440px 的浅深色布局，共 190 组检查；未见横向溢出、公式错误或脚本异常，窄屏宽公式仍可独立滚动。
- 同样的 390×844px、缓存关闭、下载 1,000,000 字节/秒、延迟 120ms 模拟条件下，示例文章累计布局偏移从约 0.126 降至 0.0105；首屏内容绘制约 1.32 秒。全部字体就绪约 19.41 秒，字体体积仍是冷加载的待优化项。
- 规范、19 项 JavaScript 与 29 项 Ruby 检查、严格 Jekyll 构建、1532 项资源引用和完整浏览器回归通过；RSS 保持原始正文，标题锚点与含公式的表格结构核对通过。
- 以上证明公式加载修复可用；完整字体加载、全站视觉终审及真机软键盘体验仍待复核。

## 字体分片与首次布局复核（2026-10-02）

- 思源宋体的完整 30,930 个字符由 55 个网页分片覆盖，常用分片为 743,544 字节；LXGW Bright Code GB 的完整 26,569 个字符由 43 个分片覆盖，常用分片为 554,400 字节。原字体文件与 Ubuntu Mono 保留。
- 独立读取原字体和所有分片，逐字符核对轮廓、水平与垂直度量、hinting、授权记录以及变体字；思源同时核对 250、400、700、900 字重和可变轴。浏览器验证全部 96 个备用分片实际加载，包含粗斜体代码、五档正文字重与变体字的截图逐像素一致。
- 两站合计 39 张页面截图在字体分片前后逐像素一致。手机首次布局修复另行复核，不用该截图结果替代对布局变化的验证。
- 字体声明合并进已有样式包，避免新增样式请求；分片使用内容摘要文件名。默认构建只使用已提交的分片，不需要 Python 或 FontTools。常规检查核对原字体与分片摘要、CSS 声明和完整字符范围。
- 在 390×844px、缓存关闭、下载 1,000,000 字节/秒、延迟 120ms 条件下，示例文章字体请求由 16,783,668 降至 1,470,264 字节，字体就绪由约 19.48 秒缩短至约 3.80 秒；首页由约 12.07 秒缩短至约 2.15 秒。这些是本地模拟数据，不代表真实访问者数据。
- 修复初始化前显示桌面导航与内嵌目录造成的手机位移。人为延迟脚本 1.8 秒时，旧版正文上移 74px、搜索图标横移 204px；新版正文起点与图标位置保持不变。脚本关闭时仍可阅读文章与使用原导航。
- 当前两站各 135 组页面检查覆盖 320–1920px、浅深色、横屏、低可视高度及 200% 等效布局，没有横向溢出、描述截断、题头重叠、资源错误或脚本错误；完整浏览器交互回归通过。
- 本次构建的全部 18 篇文章完成 320、390、768、1024、1440px 的浅深色检查，共 180 组；未见页面横向溢出、公式错误或脚本异常，宽公式仍独立滚动。默认配置与 `/preview` 子路径的严格构建、资源引用检查均通过。
- 首次布局检查已纳入浏览器回归：暂停主模块初始化，分别比较字体就绪后和交互初始化后的正文起点、搜索图标位置，允许误差不超过 1px。
- 补充 Firefox 与 WebKit 的 390、1440px 浅深色复核，各完成 88 组页面检查，并验证搜索建议、键盘操作、输入法组合、失败重试、分页、手机面板和 380px 低视口中的输入；字体、公式与脚本未报错。
- 当前字体与初始化问题已有直接验证；全站八维终审继续覆盖长文完整阅读、不同浏览器和手机输入视口。真机体验尚未实测，不以模拟检查冒称真机结果。

## 流程图跨浏览器视觉修复（2026-10-02）

- 长文截图复核发现，已有示例流程图的画布异常放大到约 5,407×12,659，节点缩成细小标记。字体分片前的构建在 Chrome、Firefox 与 WebKit 中均能复现。
- 使用当前的全局 `htmlLabels: false` 配置，让节点与连线标签采用 SVG 文字；原来的 `flowchart.htmlLabels` 已弃用，全局设置优先，参见 [Mermaid 配置说明](https://mermaid.js.org/config/schema-docs/config-properties-htmllabels.html)。
- 文字恢复后继续核对截图，发现右侧和底部节点被原画布边界裁切。SVG 插入文章后重新测量实际边界并保留 8px 留白，完整展示全部节点与连线。
- 两站各完成 Chrome、Firefox、WebKit 在 320、390、1440px 浅深色下的 18 组图表检查；实际文字高度与画布内的完整可见性纳入浏览器回归，页面没有横向溢出。
- 以上是本次实际截图发现和修复的问题；终审继续检查其余内容场景，真机体验不以模拟结果代替。
